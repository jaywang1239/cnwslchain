# CNWSL 官网 · 域名归一化处理报告

日期：2026-09-28　站点：https://www.cnwslchain.com

---

## 一、你的疑问

"网站怎么显示 cnwslChain.com，帮我改成显示 www.cnwslchain.com"

## 二、排查结论：网站前端没有问题，问题在域名层面

我逐字检查了首页 HTML，**页脚显示的网址本身就是 `www.cnwslchain.com`**，
canonical、hreflang、Open Graph 全部都是 www 版本。

HTML 里出现的 50 处 `cnwslchain.com` 全都是链接地址的子串（`https://www.cnwslchain.com/...` 里
本来就包含这段字符），另有一处是邮箱 `info@cnwslchain.com`（邮箱本就不带 www，正确）。

**真正的隐患**：裸域名 `cnwslchain.com`（不带 www）访问时**直接返回 200，不做跳转**。
这会让百度把 `cnwslchain.com` 和 `www.cnwslchain.com` 判定为**两个独立网站**，导致：
- 权重分散在两个域名，两边排名都上不去
- 你在百度后台看到的"站点"很可能是按裸域名添加的
- 但网站的 canonical / sitemap / 外链全指向 www，双方信号打架

## 三、已完成的修复

在 `next.config.mjs` 中新增域名归一化规则，**裸域名所有路径永久跳转到 www**：

| 访问 | 结果 |
|---|---|
| `https://cnwslchain.com/` | → `https://www.cnwslchain.com` |
| `https://cnwslchain.com/products` | → `https://www.cnwslchain.com/products` |
| `https://cnwslchain.com/guides/selection` | → `https://www.cnwslchain.com/guides/selection` |
| `https://cnwslchain.com/en` | → `https://www.cnwslchain.com/en` |

跳转**保留完整路径**，用户不会跳到首页丢失当前位置。

**技术说明**：返回状态码为 **308**（永久重定向）。这是服务器（LiteSpeed）的标准行为，
与 301 同属永久重定向。**百度官方帮助页明确将 301 与 308 并列为「永久服务器端重定向」并推荐使用**，
权重传递效果同级，无需担心。

## 四、现在需要你在百度后台做的

1. 打开 [百度搜索资源平台](https://ziyuan.baidu.com) → **站点管理**
2. 确认站点列表里是 **`https://www.cnwslchain.com`**
   - 如果只有 `cnwslchain.com`（不带 www），请**重新添加** www 版本
   - 之后所有提交（sitemap、普通收录）都在 www 这个站点下操作
3. 添加站点时需要验证，**选「文件验证」**——把百度给的文件名发我，我传到网站根目录，秒级生效
4. 验证通过后 → **普通收录 → sitemap** → 提交：
   ```
   https://www.cnwslchain.com/sitemap.xml
   ```
   （该文件现含 2118 条 URL，已收录选型指南等新页面）

## 五、验证结果

全站自测 **9 组 → 10 组 43 项，PASS=43 / FAIL=0**，
新增 J 组持续监控域名归一化，防止将来被误改。
