# 威仕龙 PDF 批量修改工具

适用于桌面 **`wsl型号`** 文件夹里 **5374 份图片型 PDF**（文字无法选中）。

**原理：** 在 PDF 固定位置 **白底遮盖旧公司信息**，再 **写入新文字**（不修改原文件，输出到新文件夹）。

## 启动

双击 **`启动.bat`**

浏览器打开：**http://127.0.0.1:8501**

## 使用步骤

1. 确认输入文件夹：`C:\Users\Administrator\Desktop\wsl型号`
2. 填写新公司名、地址、电话、传真、邮箱
3. 右侧查看样本 PDF，**拖拽框选**遮盖区域（或手动改坐标）
4. 点击 **生成 1 份预览**，打开链接确认效果
5. 试跑 **3 份**，无误后再批量处理全部
6. 输出目录默认：`桌面\wsl型号-已更新`
7. 确认无误后，复制到网站 `public/datasheets/`

## 命令行（可选）

```bash
npm install
node process.mjs --limit=3    # 试跑 3 份
node process.mjs              # 处理全部
```

## 注意

- 不同系列 PDF 版式可能不同，坐标需先在样本上微调
- 原 PDF **不会被修改**
- 网站页脚联系方式在 `src/lib/site.ts` 单独维护
